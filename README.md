# Sahne Prompter

iPhone için tam ekran teleprompter. Kurulum gerektirmez, ana ekrana eklenip uygulama gibi çalışır.

## iPhone'a kurulum
1. Safari ile `https://kudretsahin.github.io/sahne-prompter/` adresini açın.
2. Paylaş düğmesi › **Ana Ekrana Ekle**.
3. Ana ekrandaki **Prompter** ikonundan açın. Tam ekran açılır, ilk açılıştan sonra internetsiz de çalışır.

## Özellikler
- Ayarlanabilir hız, yazı boyutu, satır aralığı, yan boşluk, okuma çizgisi
- Ayna (yatay) ve baş aşağı (dikey) mod
- 3 / 5 sn geri sayım, geçen / kalan süre
- `[Köşeli parantez]` içindeki metin sahne notu olarak gösterilir
- Dokun: oynat/duraklat, sürükle: ileri/geri
- Bluetooth klavye/kumanda: Boşluk, ↑↓ hız, ←→ PgUp/PgDn atla, +/− yazı, M ayna, Esc çıkış
- Ekran kararmaz (iOS 16.4+)
- Metinler cihazda saklanır
